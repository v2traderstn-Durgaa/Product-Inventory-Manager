SECTION 5: PAYMENT — RAZORPAY INTEGRATION
═══════════════════════════════════════════════

FLOW:
1. Frontend: user clicks "Pay Now" → POST /api/v1/orders → server creates Razorpay order → returns {razorpay_order_id, amount, currency, key_id}
2. Frontend: opens Razorpay checkout modal with returned data
3. User pays → Razorpay returns {razorpay_payment_id, razorpay_order_id, razorpay_signature}
4. Frontend: POST /api/v1/orders/verify-payment with those three fields
5. Server: verify HMAC signature using razorpay_order_id + razorpay_payment_id + secret
6. If valid: update order status to 'confirmed', payment_status to 'paid', send order confirmation email
7. Frontend: show success page with order number

Razorpay options config:
- key: RAZORPAY_KEY_ID (from env)
- currency: INR
- name: "Angaayam Foods"
- description: "Order #{order_number}"
- image: brand logo URL
- prefill: {name, email, contact}
- theme: {color: "#1a5c2e"} — forest green

For paid events: same flow, create a Razorpay order for event price.
